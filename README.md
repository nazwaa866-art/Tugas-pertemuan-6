# Catatan Tugas Kuliah (Tugas Pertemuan 6 PAW)

Aplikasi web pengelola daftar tugas kuliah menggunakan TypeScript dan Vite untuk mata kuliah Pengembangan Aplikasi Web.

## Fitur Aplikasi
- Menampilkan daftar tugas kuliah beserta status (Belum Selesai / Selesai)
- Menambahkan tugas kuliah baru dengan validasi input
- Mengedit dan menghapus tugas kuliah
- Filter berdasarkan status dan pencarian kata kunci
- Penyimpanan lokal menggunakan `localStorage` melalui repository generik TypeScript

## Status Rilis
